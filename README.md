## Founder — [TriHerm](https://www.triherm.com/)

TriHerm builds practical software and AI systems for businesses today while exploring how software agents may eventually discover, coordinate, transact with, and execute work through existing businesses and operational systems.

The approach is grounded in real products and workflows rather than speculative infrastructure in isolation.

## Selected work

### [TriHerm Labs](https://github.com/TriHerm)

- [**TypeOpen**](https://github.com/TriHerm/TypeOpen) — lightweight, open-source Markdown editor for macOS.

### [ScriptCut](https://github.com/FernandoAbishai/ScriptCut)
Local-first desktop video production software built around transcript editing, AI-assisted workflows, FFmpeg, and creator-owned processing.

### [agent-service-interop](https://github.com/FernandoAbishai/agent-service-interop)
An interoperability experiment for exposing real-world service workflows to multiple agent-facing protocols while preserving the underlying business system as the operational source of truth.
